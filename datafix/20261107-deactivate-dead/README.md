# 20261107-deactivate-dead

掲載終了済み物件のサイト残留を解消する一括失効。

- 背景: ユーザーが掲載終了済み SUUMO ページをサイトで踏んだ
  (jnc_000110298646, last_seen=11/1, 6日間残留)
- 生きている物件は毎日の全駅スクレイプで全件再確認されるため
  3日以上見つからない = 掲載終了と断定できる (active は
  ほぼ last_seen=今日 に二極化する実測)
- 閾値を 7日 -> 3日 に変更し、現行在庫を一括失効
- 二重防壁: 詳細取得時の掲載終了ページ検知 (detail_scraper)、
  サイト/app 母集団の max_age_days=3
